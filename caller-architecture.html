Hermes turns intent into a call briefing

The originating Hermes agent uses the installed urgent-caller skill. It authors the minimum context the voice agent needs and retains the originating Hermes session lineage.

reason: "Daily omega-3 check-in" relevant_context: "Ask whether Chirag took it today" desired_outcome: "Record yes with Hermes" urgency: "normal" opening_question: "Did you take your omega-3 today?"
Prompt injection

Five layers, injected at different times

1Hermes briefing

Hermes converts the user request into reason, relevant_context, desired_outcome, urgency and opening_question.

2Voice instructions

The Worker adds the concise phone-agent rules and embeds the briefing as untrusted JSON inside <call_briefing>.

3Ringing guard

The connector adds: remain silent until Caller confirms that the user answered.

4Pickup event

After CallKit answers, the connector injects a trusted <caller_event> with appendText.

5Opening speech

The Hermes-authored question is sent with appendSpeech. Sol voices it; subsequent dialogue is generated live.
